# VsCode Shortcut for Programmers

-------------------------------------------------------------------------------------------------------------------
1) Home = Moves the cursor to the beginning of the current line.

2) End = Moves the cursor to the end of the current line.

3) Ctrl + Left/Right Arrow = Moves the cursor to the beginning of the left or right word.

4) Ctrl + Shift + Left/Right Arrow = Selects the word to the left or right of the cursor.

5) Ctrl + Delete = Deletes the word to the right of the cursor.

6) Alt + Up/Down Arrow = Moves the current line or selection up or down.

7) Shift + Alt + Up/Down Arrow = Copies the current line or selection up or down.

8) Shift + End/Home = Selects the text from the current cursor position to the end or beginning of the line.

9) Ctrl + D = Selects the next occurrence of the current word or selection.

10) Ctrl + F = Opens the Find widget to search within the current file.
